# Sound assets

- `video-call-1.mp3`, `video-call-2.mp3`, `video-call-3.mp3`: audio tracks extracted from the user's `1.mp4`, `2.mp4`, and `3.mp4`. The app randomly plays one of these files after each click in both Chinese and English.
- `cow-moos-cc0.mp3`: Cow Moos #1 from BigSoundBank, CC0 public domain, used as a fallback if the extracted clips cannot be played.
  Source: https://bigsoundbank.com/cow-moos-s0546.html
